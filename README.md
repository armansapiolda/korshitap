# 🏔 KORSHI TAP — сервис поиска соседей и совместной аренды (Алматы, Астана, Шымкент)

> **«Найди место. Найди соседа. Заселись.»**

> ℹ️ Актуальная архитектура и бизнес-правила описаны в [`CLAUDE.md`](CLAUDE.md). Ниже часть разделов описывает старый Tinder-слой (свайпы, веса), который остался в коде, но не выведен в главное меню.

**KORSHI TAP** — это Telegram-бот и локальная платформа для интеллектуального подбора подселения, свободных комнат/койко-мест и совместимых соседей в городе **Алматы**. 

Сервис полностью автономно работает на вашем локальном компьютере (Long Polling, база данных SQLite, локальная веб админ-панель).

---

## 🌟 Ключевые возможности

1. **Район Алматы — ключевой приоритет (35% веса в matching formula):**
   - 8 официальных районов: *Бостандыкский, Алмалинский, Медеуский, Ауэзовский, Жетысуский, Наурызбайский, Турксибский, Алатауский*.
   - Строгая изоляция: пока не просмотрены все варианты в выбранном районе, бот не переключается.
   - **Сценарий исчерпания района**: когда объявления заканчиваются, бот вежливо предлагает:
     - `[🔎 Искать в соседних районах]` (умная карта смежных районов Алматы)
     - `[📍 Выбрать другой район]`
     - `[⏳ Подождать новые объявления (🔔 Включить уведомления)]`
2. **AI-распознавание анкеты (Google Vertex AI / Gemini API):**
   - Пользователь может написать или надиктовать требования свободным текстом (например: *«Ищу подселение в Бостандыкском, бюджет до 100 тыс, заселиться с 15 сентября, не курю»*).
   - AI сам извлекает район, бюджет, дату заселения, привычки и формирует карточку подтверждения.
3. **Поддержка нескольких свободных мест в одной квартире:**
   - 3-комнатная квартира с 2 свободными местами хранится как **одно объявление** с параметром `available_places=2` и ценой за человека, что позволяет владельцу заселить сразу нескольких подходящих жильцов.
4. **Tinder-механика карточек:**
   - Карточки выводятся по одной: `[❤️ Подходит]`, `[❌ Пропустить]`, `[👀 Подробнее]`, `[🚩 Пожаловаться]`.
   - При взаимном лайке создаётся **Match** и оба пользователя получают контакт для связи в Telegram.
5. **Раздел «👥 Кто ищет»:**
   - Владельцы квартир могут просматривать подходящих соискателей в своем районе и ставить им `❤️`.
6. **Локальная веб Admin-панель (FastAPI):**
   - Доступна на `http://127.0.0.1:8000/admin`.
   - Управление пользователями, объявлениями, жалобами, просмотр активных матчей.
   - **Динамическая настройка весов matching**: ползунки весов (Район 35%, Бюджет 20% и т.д.) сохраняются в базу данных на лету без перезапуска приложения!
   - Кнопка генерации/очистки реалистичных тестовых данных Алматы.

## 🚀 Быстрый старт на вашем компьютере

### 1. Подготовка окружения
Виртуальное окружение `.venv` и зависимости уже установлены. Если вы запускаете на новой машине:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения (`.env`)
Создайте файл `.env` (скопируйте из `.env.example`):
```bash
cp .env.example .env
```

В файле `.env` укажите ваши ключи:
```env
# Токен бота от @BotFather
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_БОТА"

# --- Вариант 1: Google Cloud Vertex AI ---
AI_PROVIDER="vertex"
USE_VERTEX_AI=True
GOOGLE_CLOUD_PROJECT="ваш-gcp-project-id"
GOOGLE_CLOUD_LOCATION="us-central1"

# --- Вариант 2: Google AI Studio API Key ---
# AI_PROVIDER="gemini"
# GEMINI_API_KEY="ваш_ключ_от_Google_AI_Studio"

# --- Вариант 3: Офлайн Mock (для тестов без ключа) ---
# AI_PROVIDER="mock"

DATABASE_URL="sqlite+aiosqlite:///korshi_tap.db"
# Для реального запуска лучше Postgres:
# DATABASE_URL="postgresql+asyncpg://user:password@localhost:5432/korshi_tap"
ADMIN_HOST="127.0.0.1"
ADMIN_PORT=8000
ADMIN_USERNAME="admin"
ADMIN_PASSWORD="придумай_пароль"
```

Схема базы создаётся и обновляется миграциями Alembic автоматически при старте бота или админки.

### 3. Тестовые данные (сиды)
Сиды — фейковые анкеты, чтобы проверить поиск без реальных людей. Проще всего — кнопками на странице админки **/admin/seed** («Сгенерировать сиды» / «Удалить сиды»). Или из консоли:
```bash
.venv/bin/python -m app.seeds.test_data --count 500   # добавить 500 сидов
.venv/bin/python -m app.seeds.test_data --wipe-only   # удалить все сиды
```
Удаление затрагивает **только сиды** — реальные пользователи остаются. В боте у сида вместо «Написать» кнопка «🧪 Тестовый профиль», она никуда не ведёт.

### 4. Запуск

#### Вариант A: Запуск всего вместе (Рекомендуется)
Одновременно запускает Long Polling Telegram-бота и локальную Admin-панель:
```bash
.venv/bin/python run_all.py
```

#### Вариант B: Запуск по отдельности
- **Только Telegram-бот:**
  ```bash
  .venv/bin/python run_bot.py
  ```
- **Только Admin-панель:**
  ```bash
  .venv/bin/python run_admin.py
  ```
  После запуска откройте в браузере: [http://127.0.0.1:8000/admin](http://127.0.0.1:8000/admin)
  Логин и пароль — `ADMIN_USERNAME` / `ADMIN_PASSWORD` из `.env`. Если пароль не задан, одноразовый пароль печатается в консоль при старте.

## 🧪 Запуск автоматических тестов

Проект покрыт автоматическими тестами `pytest`:
```bash
.venv/bin/pytest -v
```

Тесты проверяют:
1. `test_matching_engine.py`: Приоритет района над ценой (Бостандыкский 110 тыс. побеждает Алмалинский 100 тыс.).
2. `test_district_exhaustion.py`: Полный цикл свайпов в Бостандыкском районе → определение исчерпания → расширение на соседние районы.
3. `test_multi_places.py`: Корректная обработка квартир с несколькими свободными местами.
4. `test_ai_parsing.py`: Извлечение параметров из свободного текста соискателя.
5. `test_mutual_match.py`: Создание Match при взаимном лайке.
6. `test_admin_api.py`: Работоспособность страниц админки и обязательный логин.
7. `test_search_filters.py`: Фильтры бюджета и даты, «не показывать повторно», уведомления о новых людях, напоминания о свежести, отсутствие дублей объявлений.
8. `test_bot_flow.py`: Сквозные сценарии через настоящий диспетчер бота (анкета с несколькими районами, правка одного поля, владелец квартиры, блокировка, сиды).
9. `test_safety.py`: Удаление сидов не трогает реальных людей, карточки не ломаются от Markdown, воронка.
10. `test_postgres.py`: Миграции и основные сценарии на Postgres (запускается, если задан `TEST_POSTGRES_URL`).

Тесты работают на временной БД и mock-ИИ — настоящая `korshi_tap.db` и Vertex AI не затрагиваются.

## 📁 Структура проекта

```
korshi_tap/
├── app/
│   ├── config.py                 # Настройки (Pydantic Settings: Vertex AI, Gemini, DB)
│   ├── constants.py              # 8 районов Алматы, соседние районы, типы жилья
│   ├── db/
│   │   ├── base.py               # Async engine SQLite / PostgreSQL
│   │   └── models.py             # User, SeekerProfile, Listing, Like, Match, Report, Setting
│   ├── ai/
│   │   ├── base.py               # Интерфейс AIProvider
│   │   ├── gemini_provider.py    # Реализация Vertex AI и AI Studio
│   │   ├── mock_provider.py      # Мок-провайдер для тестов
│   │   └── factory.py            # Фабрика AI
│   ├── matching/
│   │   ├── engine.py             # Matching engine (фильтры -> веса -> AI ranking)
│   │   ├── filters.py            # Строгие фильтры по району, бюджету и полу
│   │   ├── scoring.py            # Детерминированный расчет совместимости
│   │   └── weights.py            # Конфигурация весов (Район 35% и т.д.)
│   ├── services/                 # Бизнес-логика (User, Listing, Match, Report, Search)
│   ├── bot/                      # Telegram-бот на Aiogram 3.x
│   │   ├── bot_instance.py       # Bot & Dispatcher
│   │   ├── states.py             # FSM-состояния анкет и свайпов
│   │   ├── keyboards/            # Кнопки районов, свайпов, меню
│   │   └── handlers/             # Обработчики сообщений и свайпов
│   ├── admin/                    # FastAPI Admin Web Panel + Jinja2/Tailwind
│   └── seeds/
│       └── test_data.py          # 20 пользователей, 19 объявлений Алматы
├── tests/                        # 8 automated unit & integration tests
├── run_bot.py                    # Запуск бота
├── run_admin.py                  # Запуск админки
└── run_all.py                    # Единый запуск
```
